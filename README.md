\# Storage Estimator - Feature Version



\## Purpose

A Python program that estimates the total storage needed from the number of files and the average file size.



\## How to Run

python storage\_estimator.py



\## Example Input/Output

Input:

Number of files: 100

Average file size in MB: 5



Output:

Estimated storage needed: 500.0 MB
